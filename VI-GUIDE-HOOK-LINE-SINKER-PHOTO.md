# Hook, Line & Sinker final photo

Installs the final missing real directory image from Hook, Line & Sinker's official St. Thomas website.

The card displays a visible source credit linking to `https://hlsvi.com/`.

```bash
tar -xzf public/vi-guide-hook-line-sinker-photo.tar.gz -C .
rm -rf .next
npm run build
npm run dev
```
