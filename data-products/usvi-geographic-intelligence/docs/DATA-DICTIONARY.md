# Estate Intelligence Data Dictionary

## Canonical CSV

`canonical_id` — stable canonical estate identifier; currently the modern estate GEOID.

`geoid` — source GEOID retained explicitly for GIS joins.

`estate_code` — source estate code when present.

`name` — canonical display name for the modern estate.

`full_name` — fuller source/display name when available.

`normalized_name` — comparison key generated by Unicode normalization, punctuation removal, `estate` removal, whitespace folding, and lowercasing. This is a matching aid, not display text.

`aliases` — normalized product-level identity aliases carried from the enriched source record.

`island` — `stt`, `stj`, or `stx`.

`county` — source county code where present.

`centroid_lat`, `centroid_lng` — centroid coordinates used for quality checks and map placement.

`internal_point_lat`, `internal_point_lng` — internal point when supplied by the source.

`sources` — source/provenance identifiers carried by the enriched estate record.

`historical_notes` — historical notes associated with the estate.

`dictionary_names` — names attached through Geographic Dictionary matches.

`geometry_type` — `Polygon`, `MultiPolygon`, or blank when geometry is absent.

## Audit CSV

`canonical_id` — canonical estate GEOID.

`canonical_name` — modern canonical estate name.

`source_name` — pipe-separated source identifiers from the enriched record.

`existing_name` — current full/display name in the enriched estate record.

`match_type` — `MATCHED`, `ALIAS`, `DUPLICATE`, `MISSING`, `CONFLICT`, or `NEEDS_REVIEW`.

`island` — canonical island assignment.

`coordinate_status` — `OK`, `MISSING`, or `OUT_OF_BOUNDS` using a deliberately broad USVI guardrail.

`geometry_status` — `OK` or `MISSING`.

`provenance_status` — `OK` when at least one source identifier is present, otherwise `MISSING`.

`confidence` — `high`, `medium`, or `low` confidence in the automatic classification.

`review_reason` — human-readable reason for the classification.

## GeoJSON

The GeoJSON export contains the estate geometry plus canonical identity fields, aliases, island/county context, and source identifiers. Records without geometry are excluded from the GeoJSON but remain visible in the CSV audit.
